# pencil-voice: notes for agents

- `dist/` is committed and CI checks it matches `src/`. Always run `npm run build` (or `npm test`, which builds) after
  editing `src/`. `src/processor-source.ts` is generated by `scripts/build.mjs` and git-ignored.
- `src/pencil-processor.js` runs on the audio thread and must not allocate in `process()`. Garbage collection there
  causes audible clicks. Filter coefficients live in preallocated objects (`newCoef()`) and are refilled in place.
- Don't `push(...arr)` stroke arrays: one long subpath (about 100k+ resampled points) overflows V8's argument limit
  with `RangeError: Maximum call stack size exceeded`. `test/stroke.test.js` pins this with a 1,000,000 px subpath.
- To change the synth without changing its sound, prove the output is bit-identical. Load the processor in Node with
  shimmed globals (`sampleRate`, `AudioWorkletProcessor`, `registerProcessor`) and a seeded `Math.random`, render a few
  thousand blocks (with bursts and a `config` message) before and after, and `cmp` the raw samples. Baseline cost is
  about 27 µs per 128-sample block (graphite, M-series), against a 2,667 µs budget.
- `npm run test:browser` clicks "Write it" only once. To check replays, click it several times and count `resize`
  listeners: a follower that is never disposed leaks one listener (and a forced layout per resize).
